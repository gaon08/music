# HUSH — your sound, your space

A modern, personal music archive. Browse clean, cover-led collections, save notes about each track, and listen to audio files you add.

## Run it

Open `index.html` in a modern browser, or publish the repository with GitHub Pages.

## Features

- Korean, English, Japanese, and Chinese interface
- Contemporary dark UI with luminous accent color, responsive album-card grid, and subtle motion
- Search by title, artist, album, genre, or notes; filter by genre and favorites
- Add, edit, and remove tracks with title, artist, album, year, genre, description, cover art, and optional audio
- Built-in player with seek, volume, previous/next, shuffle, and repeat
- Track details and uploaded cover/audio files are stored locally in IndexedDB in this browser; nothing is uploaded to a server
- Keyboard dismissible dialogs, visible focus states, and reduced-motion support

## Storage note

Your collection is tied to this browser and device. It will not sync to another device, and clearing site data may remove it. Large audio and image files may exceed the browser's available storage. Use music and artwork you have permission to store and play.
