# HUSH — A library of sound

A small, interactive music library: browse songs as books on genre shelves, open a detail card with notes and metadata, and listen to audio files you add.

## Run it

This is a static site. Open `index.html` in a modern browser, or publish the repository with GitHub Pages.

## Features

- Korean, English, Japanese, and Chinese interface
- Genre-grouped animated shelves, search, and genre filtering
- Song details: title, artist, album, year, genre, and your own description
- Add and remove songs, optionally with a local audio file
- Built-in player with seek, volume, previous, and next controls
- Song details and audio files are stored locally in the browser using IndexedDB; they are not uploaded to a server
- Responsive layout and reduced-motion support

## Storage note

The collection belongs to the browser and device where it was added. Clearing site data or using another browser/device will not carry it over. Large audio files may exceed the browser's available storage. Use audio you have the right to store and play.
